## Как устроена позиция

- **Номер** — строка (`"31"`, `"31_1"`).
- **Наименование** — текст; часто содержит **дополнительные условия**:
  «за исключением …» (19), «кроме …» (30), «только …» (5), «соответствующие кодам … номенклатурной классификации медизделий» (59).
  Эти условия не сводятся к кодам ОКПД2 → показываем их пользователю и ставим флаг «у позиции есть условия».
- **Коды ОКПД2** — список (99 позиций имеют несколько кодов). Уровень кода разный:
  13 — раздел/класс (`"22"`), 32 — 2 уровня, 366 — 3 уровня, 772 — 4 уровня. Код позиции покрывает все коды ниже по иерархии.
- **Примечание** — «Позиция дополнительно включена с … постановлением …» (44 позиции).
- **Пересечения**: один код может входить в несколько позиций одного приложения
  (например, `32.50.50` — 42 позиции приложения 2, различаются наименованием медизделия)
  и в разные приложения одновременно (`26.20.11` — прил. 2 п. 195 и прил. 3 п. 37, доля 80%).

Примеры (как в данных):
```
прил.1 п.10  «Бумага и картон»                                  [17.12]
прил.2 п.195 «Компьютеры портативные …» (по набору pp1875.json)  [26.20.11]
прил.3 п.1   «Щебень»                                            [08.12.12.140]  доля 80%
```

## Выводы для реализации (отличия от первоначальной спеки)

1. Позиция = (приложение, номер, наименование, **список** кодов, доля, примечание). В БД — одна строка `npa_item` на позицию, коды в массиве.
2. Кодовых исключений в источнике нет: «за исключением» записано текстом. Поле `exclusions` (коды) поддерживается форматом загрузки для ручного уточнения, но в базовой редакции пустое. Позиции с текстовыми условиями помечаются `has_conditions`.
3. Если код попадает в несколько позиций одного приложения, позиции упорядочиваются по смысловой близости наименования позиции к товару.
4. Формат загрузки новой редакции — JSON (как `data/npa/pp1875.json`) или XLSX с колонками
   `appendix | item_no | title | codes (через запятую) | quota | exclusions | note`.
5. Два кода позиций (`26.80.13.000`, `25.99.26.000`) отсутствуют в ОКПД2 — это не ошибка загрузки, а предупреждение.

## Что проверить команде вручную
