# Замеры

Все цифры получены на CPU скриптами `backend/scripts/eval.py` (точность) и `backend/scripts/bench.py` (скорость).
Наборы: `dev` — 88 реальных позиций из закупок (на нём настраивали), `testset` — 32 «чистых» наименования
(похожи на то, что даст жюри), `stress` — 192 вариации наименований testset (опечатки, артикулы, количество,
шаблоны ЕИС). `holdout` не используется до финального замера.

## Актуальные — модель по умолчанию (`BOBUS2317/e5-large-pp1875-onnx`, ONNX int8 AVX2)

| Отчёт | Вердикт по ПП | Код ОКПД2, top-1 |
|---|---|---|
| [eval_testset_ft_avx2.md](eval_testset_ft_avx2.md) | **100%** (32/32) | 96.9% |
| [eval_stress_ft_avx2.md](eval_stress_ft_avx2.md) | **100%** (192/192) | 96.9% |
| [eval_dev_ft_avx2.md](eval_dev_ft_avx2.md) | **87.5%** (77/88) | 63.6% |

Скорость — [bench.md](bench.md) (через HTTP API, 26.10.2026): 1 товар p50 0.12 с, p95 0.18 с; 100 товаров 13.9 с
(критерии ТЗ: < 5 с и < 2 мин).

## Сравнение вариантов модели (26.10.2026)

Исходная `intfloat/multilingual-e5-large` без дообучения, подключается настройками `.env` (раздел «Другая модель» в [README](../README.md#другая-модель)).

| Вариант | dev: вердикт / код top-1 | testset | stress |
|---|---|---|---|
| Дообученная, ONNX int8 (по умолчанию) | 87.5% / **63.6%** | 100% | 100% |
| Исходная, ONNX int8 — [dev](eval_dev_onnx.md), [testset](eval_testset_onnx.md), [stress](eval_stress_onnx.md) | **90.9%** / 54.5% | 100% | 100% |
| Исходная, PyTorch — [dev](eval_dev_torch.md), [testset](eval_testset_torch.md), [stress](eval_stress_torch.md) | 88.6% / 55.7% | 100% | 100% |
