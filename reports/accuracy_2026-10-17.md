## Шаги и вклад каждого (вердикт dev / testset)

| Шаг | dev | testset | Что |
|---|---|---|---|
| 0. Исходно | 78.4% | 87.5% | |
| 1. Честная оценка | 81.8% | 87.5% | `label_fixes.csv` (2 явные ошибки заказчиков) + эталон-группа засчитывается, если вердикт совпал хотя бы с одним кодом группы. В отчёте есть и цифра «как в наборе» |
| 2. Сокращения, товары выше услуг | 81.8% | 90.6% | ДСП/ЛДСП/ДВП/МДФ/ПВХ/АКБ/СИЗ… в `normalize.py`; `rerank.prefer_goods`: без слов «услуги/ремонт/аренда…» коды-услуги уходят ниже товаров («Автомобиль легковой» ≠ «Услуги по аренде автомобилей») |
| 3. Поиск по словам (BM25) | 80.7% | 93.8% | `lexical.py`: BM25 с русским стеммингом по текстам кодов, объединение с поиском по смыслу через RRF (вес 0.5) |
| 4. Синонимы | 83.0% | 93.8% | **Исправлена ошибка**: 119 из 561 синонима (21%) молча терялись — записи без шаблона привязывались к коду группы, а индекс строится только по кодам нижнего уровня. Среди потерянных — «lada», «дсп», «асинхронный двигатель», «хлеб», «цемент». + синонимы для канцелярской мелочи, мебели залов, спецобуви, знаков различия, стройматериалов, продуктов |
| 5. Медизделия | **86.4%** | **93.8%** | `rerank.prefer_medical`: при пометке ЕИС «является медицинским изделием» коды медицинских разделов (32.50, 21.20, 26.60, 22.19.60) идут первыми («Цемент костный» ≠ «Цементы общестроительные») |

Поиск по словам при текущих синонимах: dev 83.0% → 84.1% без него, testset 93.8% → 90.6% без него (ничья по сумме).
Оставлен включённым — на «чистых» наименованиях он заметно лучше (top-3 testset 100%). Выключается `LEXICAL_SEARCH=false`.

## Честно о рисках

- Часть синонимов покрывает группы, где ошибалась модель на dev (канцтовары, спецобувь) — это частые товары
  госзакупок, но цифра dev из-за этого может быть немного оптимистичной. **Непредвзятая проверка — `holdout`, один раз в конце.**
- Оставшиеся ошибки dev: в основном медизделия, где заказчики сами ставят разные коды на похожие товары,
  и спорные соседние коды (телевизор `.120`/`.121`, счётчик `.130`/`.139`, коммутатор).
